-- 1. Enable Row Level Security (RLS) on sensitive profiles
ALTER TABLE public.users ENABLE ROW LEVEL SECURITY;

-- 2. Define granular policy: isolate customer records to owner token
CREATE POLICY "Users can only read and update own data"
ON public.users FOR ALL
TO authenticated
USING ( auth.uid() = id )
WITH CHECK ( auth.uid() = id );

Enforce user isolation and data governance directly at the database engine layer. Eliminates complex middle-tier authentication handlers.
