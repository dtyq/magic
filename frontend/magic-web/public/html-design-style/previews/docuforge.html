Retrieve Document Stream

Returns a paginated list of compiled AST document nodes with full markdown frontmatter metadata and vector embeddings.

Note: Requires Bearer token with read:docs authorization scope.
Response Format: application/json (streamed)
import { DocuForgeClient } from "@docuforge/sdk";

const client = new DocuForgeClient({ apiKey: process.env.DOCU_KEY });
const { data, pagination } = await client.documents.list({
  limit: 20,
  status: "published"
});
