>>> Explain how unified memory speeds up KV-cache allocation.
Unified memory allows the CPU and GPU to address the same physical LPDDR5X RAM pool without PCIe transfer overhead. During LLM generation, KV-cache vectors reside in zero-copy shared memory, enabling instantaneous flash-attention lookups at up to 400 GB/s bandwidth.
