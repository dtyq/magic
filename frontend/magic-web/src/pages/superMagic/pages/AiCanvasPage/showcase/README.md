# AI 画布首页内置展示作品

这些作品用于 AI 画布首页的首屏画布装饰和灵感墙兜底。设计数字员工（`design`）配置了灵感后，页面会优先使用后台配置。

## 添加作品

1. 生成或收集作品原图，原图保存在仓库之外。
2. 转成高质量 WebP 放到 `images/`。图片文件必须走 Git LFS。
3. 在 `index.ts` 的 `AI_CANVAS_SHOWCASE` 中导入图片，并填写 `kind`、中英文 `title` 和生成它用的 `prompt`。
4. 在下表补一行记录。

主题：黄昏海边的少女与柯基。先生成角色设定，再把它作为参考图生成海报和分镜，保证角色一致；分镜 03 由分镜 02 只改背景得到，对应首屏便签上的修改。原图由用户在外部平台生成（2026-10-21 提供；product-02、product-03 同日补充，三张产品图在首屏以扇形展开），这里按原尺寸转为 WebP（`cwebp -q 86 -m 6 -metadata none`）。

所有提示词共用的约束：3D 动画电影画风、柔和体积光、桃粉／珊瑚／薰衣草紫／深靛蓝的黄昏色调；禁止文字、Logo、水印、边框、拼贴和 UI 元素。
