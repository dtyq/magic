# 后台-系统能力配置类型

本文仅整理后台「系统能力」中各能力的配置类型。配置类型为「服务商」时，列出可选服务商；配置类型为「模型」时，通过平台模型列表选择模型。

| 中文名称 | 能力 code | 配置类型 | 可选服务商 |
| --- | --- | --- | --- |
| OCR 识别 | `ocr` | 服务商 | Volcengine |
| 互联网搜索 | `web_search` | 服务商 | Magic API、Bing、Cloudsway、Baidu、Doubao |
| 图片搜索 | `image_search` | 服务商 | Bing、Cloudsway、Google、Doubao |
| 实时语音识别 | `realtime_speech_recognition` | 服务商 | Volcengine |
| 音频文件识别 | `audio_file_recognition` | 服务商 | Volcengine |
| 网页爬取 | `web_scrape` | 服务商 | Magic API、Bing、Cloudsway |
| 去背景 | `image_remove_background` | 服务商 | 官方代理、官方服务 |
| 扩图 | `image_expand` | 服务商 | 即梦、官方代理服务、火山引擎 |
| 橡皮擦 | `image_eraser` | 服务商 | 即梦、官方代理服务、火山引擎 |
| 天气查询 | `weather_forecast` | 服务商 | AiData |
| 自动补全 | `auto_completion` | 模型 | - |
| 内容总结 | `content_summary` | 模型 | - |
| 视觉理解 | `visual_understanding` | 模型 | - |
| 智能重命名 | `smart_rename` | 模型 | - |
| AI 优化 | `ai_optimization` | 模型 | - |
| 图片转换高清 | `image_convert_high` | 模型 | - |
| 知识库嵌入模型 | `knowledge_base_embedding_model` | 模型 | - |
| 知识库视觉理解能力 | `knowledge_base_visual_understanding` | 模型 | - |
| 追加提问 | `follow_up_questions` | 模型 | - |
| 视频理解 | `video_understanding` | 模型 | - |
| 深度写作 | `super_magic_deep_write` | 模型 | - |
| 内容净化 | `super_magic_purify` | 模型 | - |
| 智能文件名 | `super_magic_smart_filename` | 模型 | - |
| 上下文压缩 | `super_magic_compact` | 模型 | - |
| 音频分析 | `super_magic_analysis_audio` | 模型 | - |
| 生图提示词补全 | `image_prompt_completion` | 模型 | - |
