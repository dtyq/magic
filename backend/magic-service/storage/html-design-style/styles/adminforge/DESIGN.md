# AdminForge

Dense, utilitarian, zero-nonsense.

## Overview

AdminForge is a design system purpose-built for internal admin panels and back-office tools where efficiency trumps aesthetics. The philosophy is ruthless pragmatism — every element earns its space through function, not decoration. Flat surfaces with crisp borders replace shadows, compact spacing packs maximum data per screen.

## Colors

- **Primary** (#475569): Primary actions, active nav items, table selections
- **Secondary** (#3B82F6): Links, informational highlights, secondary actions
- **Tertiary** (#F59E0B): Warnings, flagged records, attention badges
- **Background** (#F1F5F9): App-level canvas, gray foundation
- **Surface** (#FFFFFF): Cards, panels, table containers
- **Success** (#22C55E)
- **Warning** (#F59E0B)
- **Error** (#EF4444)
- **Info** (#3B82F6)

## Do's and Don'ts
- Do optimize every table for keyboard navigation
- Don't use shadows for elevation — AdminForge uses borders and background contrast only
- Don't use animation durations longer than 150ms — admin users expect instant feedback
