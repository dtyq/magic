List all users

GET /v1/users

Returns a paginated list of users in your workspace. Results are ordered by registration timestamp in descending order. Use query parameters to filter by role or status.

Bearer Authentication required. Include your secret API key in the Authorization header as a Bearer token.

Query Parameters

Parameter Description
limit
integer • optional
Number of results to return between 1 and 100. Defaults to 20.
starting_after
string • optional
Cursor object identifier for pagination. Fetches the page following this cursor ID.
status REQUIRED
string • enum
Filter users by account state: active, invited, or suspended.
role
string • optional
Filter workspace members by permission tier: admin, developer, or viewer.
