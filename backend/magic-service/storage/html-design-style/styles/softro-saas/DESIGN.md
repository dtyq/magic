# Softro SaaS

## Overview
A modern SaaS and startup-focused interface built around high-conversion landing page architecture. The design language is energetic, polished, and visually layered with bold typography, animated gradients, oversized spacing, and vibrant accent colors. The interface blends startup marketing aesthetics with enterprise SaaS structure — balancing strong visual impact with clear product communication. Large hero sections, curved decorative shapes, floating dashboard mockups, and conversion-oriented layouts create an ambitious and tech-forward mood.

The visual identity prioritizes:
- Product storytelling
- Conversion-driven CTA placement
- Modern startup branding
- Trust-building through metrics and testimonials
- Smooth animated interactions
- Responsive marketing layouts

The overall experience feels premium, scalable, and investor-ready.

## Typography
- **Display Font**: Manrope
- **Body Font**: Inter
- **Code Font**: JetBrains Mono

Typography emphasizes bold startup-style marketing hierarchy with large, aggressive headlines and compact supporting text. Headlines use extra-bold weights with tight tracking to maximize impact. Body text remains clean and highly readable with neutral spacing. Product metrics and pricing elements use semi-bold typography for emphasis. UI labels and secondary navigation rely on medium-weight text for clarity.

Type scale: Hero 76px, Display 60px, Section heading 42px, Subheading 28px, Card title 22px, Body 16px, Small 14px, Caption 12px, Overline 11px uppercase.

## Elevation
The interface uses layered shadows and floating glass-like surfaces to create depth and motion. Cards and screenshots appear elevated above the background using large soft shadows and subtle blur effects. Interactive elements increase elevation on hover with smooth animated transitions.

- Base card shadow: `0 10px 30px rgba(15,23,42,0.08)`
- Hover card shadow: `0 20px 50px rgba(15,23,42,0.14)`
- Hero media shadow: `0 30px 80px rgba(124,58,237,0.20)`
- Button glow: `0 8px 24px rgba(124,58,237,0.35)`
- Hover lift: `translateY(-3px)`
- Focus ring: `0 0 0 3px rgba(124,58,237,0.18)`

Floating dashboard visuals often combine shadows with gradient overlays and soft blur backgrounds.

## Components
- **Buttons**: Primary buttons use solid violet backgrounds with white text, 10px radius, and medium-to-semibold weight. Secondary buttons use white backgrounds with subtle borders. Gradient buttons are used in promotional hero areas. Hover states slightly lift the button while increasing glow intensity. Sizes: small (34px), medium (42px), large (50px).
- **Cards**: Rounded white surfaces with soft shadows and generous padding. Pricing cards, feature blocks, and testimonial panels use 20px–24px radius with layered hover effects. Featured cards may include subtle gradient overlays.
- **Inputs**: Rounded 10px inputs with soft borders and spacious padding. Focus state changes border color to violet with glowing outer ring. Placeholder text uses muted gray.
- **Pricing Tables**: Multi-column pricing layouts with emphasized “recommended” plans using gradient borders or elevated positioning.
- **Hero Dashboard Mockups**: Floating application previews layered over blurred gradients and abstract shapes. Mockups often use stacked cards and subtle motion animations.
- **Feature Blocks**: Alternating split-layout sections with large illustrations/screenshots paired with concise feature descriptions and bullet lists.
- **Statistics Panels**: Large numerical metrics combined with minimal labels and icon accents. Frequently arranged in horizontal grids.
- **Testimonials**: Rounded cards with avatar images, quote text, and company information. Often displayed in carousel or masonry layouts.
- **Navigation**: Sticky transparent navbar that transitions into a blurred solid background on scroll. CTA button aligned right. Mobile layout collapses into animated drawer navigation.
- **Footer**: Dark multi-column footer with grouped navigation links, newsletter forms, social icons, and brand messaging.

## Border Radius
- 6px: Tags, small badges
- 10px: Buttons, inputs, compact controls
- 14px: Dropdowns, small cards
- 20px: Feature cards, pricing blocks, testimonials
- 24px: Hero visuals, large dashboard panels
- 9999px: Pills, avatars, floating status indicators

## Motion
Motion design is highly visible but remains smooth and premium rather than flashy.

- Transition timing: `250ms–350ms ease`
- Hover lift: `translateY(-3px)`
- Floating animation: slow vertical oscillation for hero visuals
- Scroll reveal: fade-up with staggered timing
- Gradient animations: slow shifting background gradients
- Navigation transition: transparent to blurred solid state on scroll
- Button glow intensifies on hover

Animations are used to reinforce the futuristic SaaS identity.

## Layout Principles
- Use oversized hero spacing to establish visual authority
- Maintain strong separation between content zones
- Prioritize visual storytelling through dashboard imagery
- Use asymmetrical layouts for dynamic startup aesthetics
- Keep CTAs visible throughout the page flow
- Alternate light and dark sections for visual rhythm
- Maintain high readability despite layered visuals

## Imagery & Visual Style
- Floating SaaS dashboard mockups
- Abstract gradient blobs and glow effects
- Layered UI screenshots with soft blur backgrounds
- Rounded illustrations and iconography
- Minimal outline icons paired with vibrant accent gradients
- Dark/light section contrast used to create visual pacing

Visuals are designed to feel modern, ambitious, and high-growth oriented.

## Do's and Don'ts
- Do use violet (#7C3AED) consistently for interactive emphasis and brand recognition
- Do maintain large whitespace around hero and feature sections
- Do use layered shadows and gradients sparingly to create depth
- Do prioritize dashboard visuals and product screenshots
- Do maintain consistent rounded corner scaling across all components
- Don’t overcrowd layouts with excessive text density
- Don’t mix unrelated accent colors outside the defined palette
- Don’t use flat static hero sections without motion or layered visuals
- Don’t apply heavy shadows to every element simultaneously
- Don’t reduce CTA visibility within long content sections
- Don’t introduce sharp-cornered cards that break the visual language
